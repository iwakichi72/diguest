# Diguest — Macアプリ MVP仕様

## MVPの定義

「SwiftUIで動くローカルMacアプリが、Ollamaと対話しながら1セッションの思考掘り下げを行い、Markdownとして手元に保存・再読できる」状態をMVPとする。

## 実装前提

- SwiftUI
- macOS 13以上
- Ollama HTTP API
- Apple Speech on-device音声入力
- ローカルファイルシステム保存
- DBなし、外部AI APIなし、シングルユーザー前提

## In Scope

- ホーム画面から新規セッションを開始できる
- テーマを入力できる
- Ollama接続状態を確認できる
- ユーザー発言をOllamaへストリーミング送信できる
- Diguestは問い、整理、仮説を中心に応答する
- テキスト入力できる
- 対応環境ではオンデバイス音声入力できる
- 音声認識がオンデバイス非対応の場合、ネットワーク認識へフォールバックしない
- セッション終了時にMarkdownを生成する
- 要約生成に失敗しても対話ログだけは保存できる
- 保存前にMarkdownを確認できる
- `~/diguest/` または設定値の保存先にMarkdown保存できる
- 保存済みノートを一覧から開ける
- Ollama URL、モデル、保存先を設定できる

## Out of Scope

- Web版UI
- Next.js API routes
- ブラウザ音声入力
- 複数ユーザー対応
- DB保存
- 外部AI API連携
- クラウド同期
- タグ、検索、統計、ストリーク
- AIによる過去ノート自動参照

## Markdownフォーマット

```markdown
---
date: 2026-05-12T10:30:00Z
theme: <ユーザーが入力したテーマ>
model: <使用したOllamaモデル名>
turns: <ユーザー発言数>
---

# <テーマ>

## 対話の要約

<AIが生成するセッション全体の要約>

## 掘り出されたもの

- <AIが構造化した思考・発見・仮説>

## 対話ログ

**You:**

<ユーザー発言>

---

**Diguest:**

<AI発言>

---
_Generated by Diguest_
```

## 守ること

- ログだけでも必ず残す
- 助言を主役にしない
- ノートを管理対象にしすぎない
- 音声入力はローカル完結を崩さない
