# Diguest — MVP仕様

## MVPの定義

「Ollamaで動くCLI対話ツールが、1セッションの思考掘り下げ対話を行い、Markdownとして保存できる」状態をMVPとする。

## 機能スコープ

### In Scope（MVP）

#### セッション管理
- セッション開始コマンド（`python main.py` または `diguest start`）
- セッション開始時にテーマ入力を促す
- `exit` / `quit` / `終わり` でセッション終了
- セッション終了時にMarkdown自動保存

#### 対話エンジン
- Ollamaへのストリーミング応答（`/api/chat` エンドポイント）
- システムプロンプトによるAIの振る舞い制御
- 対話履歴をセッション内メモリで管理（リスト）
- モデル名は設定ファイルで指定

#### Markdown生成・保存
- ファイル名フォーマット: `YYYYMMDD_HHMMSS_<テーマ>.md`
- 保存先: `~/diguest/` または設定で変更可能
- Markdownの構造（後述）

#### 設定
- `config.toml` で以下を設定可能:
  - Ollamaのbase URL（デフォルト: `http://localhost:11434`）
  - 使用モデル名（デフォルト: `llama3`）
  - Markdown保存先ディレクトリ

### Out of Scope（MVP以降）

- WebUI・GUI
- 過去ノートの検索・ブラウズ
- セッション間の参照・リンク
- タグ・カテゴリ管理
- Markdownのテンプレートカスタマイズ
- 複数ユーザー対応
- セッションのエクスポート（PDF等）

## Markdownフォーマット仕様

```markdown
---
date: 2024-01-15T10:30:00
theme: <ユーザーが入力したテーマ>
model: <使用したOllamaモデル名>
turns: <対話ターン数>
---

# <テーマ>

## 対話の要約

<AIが生成するセッション全体の要約（200字程度）>

## 掘り出されたもの

<AIが構造化した思考・発見・仮説のリスト>

## 対話ログ

**You:** <ユーザー発言>

**Diguest:** <AI発言>

（繰り返し）

---
_Generated by Diguest_
```

## システムプロンプト設計

```
あなたはDiguestです。ユーザーの思考を掘り下げる対話相手です。

あなたができること：
- ユーザーの発言に対して深掘りする問いを返すこと
- ユーザーの発言を構造化して反射すること
- 「こういうことを言いたいのかもしれない」という仮説を提示すること
- セッション終了時に対話をMarkdown形式でまとめること

あなたが絶対にしないこと：
- アドバイス・提案・改善案を出すこと
- ユーザーの考えを評価すること（良い・悪いと言わない）
- 「〜しましょう」「〜すべきです」という行動促進
- 情報提供・事実説明・知識の共有

応答は簡潔に。問いは1つずつ。
```

## 技術仕様

### ディレクトリ構成

```
diguest/
├── main.py              # エントリポイント
├── config.toml          # 設定ファイル
├── requirements.txt
├── diguest/
│   ├── __init__.py
│   ├── session.py       # セッション管理
│   ├── ollama.py        # Ollama通信
│   ├── markdown.py      # Markdown生成・保存
│   └── config.py        # 設定読み込み
└── tests/
    └── test_acceptance.py
```

### Ollama通信

- エンドポイント: `POST /api/chat`
- ストリーミング: `stream: true`
- エラー時: Ollamaが起動していない場合は明確なメッセージを表示して終了

### 依存ライブラリ（最小限）

```
httpx          # Ollama HTTP通信
tomllib        # 設定ファイル読み込み（Python 3.11+ 標準）
rich           # CLIの表示（optional、なければprint可）
```
