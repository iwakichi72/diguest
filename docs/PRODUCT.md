# Diguest — プロダクト定義

> 「問いで、自分の思考を掘る」

## プロダクトの本質

Diguestは、まだ言葉になっていない思考・違和感・価値観・創作テーマを掘り起こすためのローカルAIツールです。

AIとの対話を通じて、ユーザーは自分の内側にあるものを言語化します。AIはアドバイスも評価もしません。ただ問い、整理し、仮説を提示し、最終的にMarkdownとして結晶化します。

## ターゲットユーザー

- **自分専用**（シングルユーザー前提）
- 思考を掘り下げたい人：作家・研究者・アイデアを整理したいエンジニア・日記的に使いたい人
- Ollamaをローカルで動かせる技術リテラシーを持つ個人

## コアコンセプト

### AIは「問い手」であり「書き手」

AIの役割は4つに限定される：

1. **問う** — ユーザーの発言に対して深掘りする問いを返す
2. **整理する** — ユーザーの発言を構造化して反射する
3. **仮説を提示する** — 「こういうことを言いたいのかもしれない」と仮説を出す
4. **Markdown化する** — セッション終了時に対話の内容を1つのmdにまとめる

AIがしないこと：
- アドバイス・提案・改善案を出す
- ユーザーの考えを評価する（良い・悪い）
- 行動を促す（〜しましょう、〜すべきです）

### セッションの構造

```
セッション開始
  ↓
今日掘りたいテーマ・問いを入力
  ↓
AIとの対話（問い・整理・仮説）
  ↓
「終わり」でセッション終了
  ↓
Markdown生成・保存
```

### 1セッション1ファイルの原則

- セッションごとに `YYYYMMDD_HHMMSS_テーマ.md` 形式でMarkdown保存
- セッションをまたいだ参照・連結は行わない
- 過去のファイルへの読み込みもしない

## プロダクト制約

| 制約 | 理由 |
|------|------|
| Ollama前提 | 完全ローカル・プライバシー保護 |
| 外部APIなし | インターネット不要・依存なし |
| DBなし | シンプルさ・移植性 |
| Markdownのみ | 人間が読めるフォーマット・git管理可能 |
| 1セッション1md | セッションの独立性・明確な区切り |
| AIはアドバイスしない | プロダクトの哲学的核心 |

## ユーザーバリュー

DiguestはChatGPTのような「答えを出すAI」ではなく、ソクラテスの問答のような「思考を深める鏡」として機能します。

セッション後に残るMarkdownは、その日の思考の地層です。
