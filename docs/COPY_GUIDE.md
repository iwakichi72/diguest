# Diguest — コピーガイド

## 用語

- **掘り跡（ほりあと）**: 1セッションを終えて Markdown として残った成果物の呼び名。「ノート」「記録」「ログ」とは呼ばない。掘った跡が地層に残るように、対話の痕跡が手元に残るという比喩。
- **掘る**: 対話を進める動作。「送る」「やる」「実行する」とは呼ばない。
- **層 / 深さ**: 対話の進行度を表す。深度メーター・掘り跡のメタ情報で使う。

---

## ボイス&トーン

### Diguestが話すとき

Diguestは静かで、押しつけがましくない。
余計なことを言わない。感嘆符は使わない。

**使わない語彙:**
- ようこそ、ぜひ、ぜひとも、さあ、どうぞ
- 素晴らしい、いいですね、おめでとう
- 簡単です、すぐできます
- 何でもお気軽に
- ✅ 🎉 🚀 などの絵文字全般

**使う語彙:**
- 静かな命令形（「始める」「戻る」「終わる」）
- 問いかけ（「何を掘りますか？」）
- 事実の記述（「8ターン」「2025-12-01」）

## 画面別コピー

### ホーム画面

| 要素 | コピー |
|------|--------|
| ロゴ/アプリ名 | `Diguest` |
| メインの問いかけ | `今日、何を掘りますか？` |
| プライマリCTA | `新しく掘る` |
| セクション見出し | `過去の掘り跡` |
| 掘り跡が0件のとき | `まだ掘り跡はありません` |
| 設定ボタン | `設定` |

**掘り跡が0件のとき（説明文）:**
```
最初のセッションを終えると、ここに掘り跡が残ります。
```

**Ollamaが起動していないとき（ホーム上のカード）:**
見出し: `Ollamaが見つかりません`
補足: `localhost:11434 に接続できませんでした。Ollama を起動してからもう一度試してください。`
アクション: `もう一度試す` / `設定を開く`

接続済みのときはカードを表示しない。

### 新規セッション画面

| 要素 | コピー |
|------|--------|
| 画面の見出し | `今日、何を掘りますか？` |
| 入力フィールドのラベル | （ラベルなし——見出しが兼ねる） |
| プレースホルダー | `最近の違和感、問い、テーマ…` |
| 補足テキスト | `一言でも、問いの形でも。` |
| CTAボタン | `掘り始める` |
| 戻るリンク | `← 戻る` |

**入力フィールドの下の補足文（サブテキスト）:**
```
一言でも、問いの形でも。
```

補足: 「答えが出なくても大丈夫」などの安心感を与えるコピーはあえて書かない。
ユーザーはそれを求めていない——問いを立てるための場所として提示するだけでいい。

### 対話画面

| 要素 | コピー |
|------|--------|
| セッション終了ボタン | `ここで終える` |
| 入力フィールドのプレースホルダー | `（空白のまま）` |
| キーヒント | `Shift+Enter で改行 · Enter で送信` |
| 発言カウンター | `{n}回` |
| Diguestがストリーミング中 | `（カーソルのみ、テキストなし）` |

**セッション開始直後（Diguestの最初の発言）:**
Diguestは自己紹介しない。「こんにちは」も言わない。ユーザーが入力したテーマを受けて、最初の問いを返すだけ。

セッション開始直後の画面には何も書かれていない。入力フィールドだけが待っている。

**セッション終了の確認（inline バー）:**
「ここで終える」を押すと、HeaderBar 直下に静かな確認バーが出る。モーダルにはしない。

| 要素 | コピー |
|------|--------|
| 問いかけ | `今日はここで終えますか？` |
| 続行ボタン | `掘り続ける` |
| 終了ボタン | `終える` |

`Esc` キーで「掘り続ける」（破棄）にフォールバックする。

### エラー・空状態のコピー

#### Ollama未起動

```
Ollamaが見つかりません
```

補足テキスト:
```
localhost:11434 に接続できませんでした。
Ollama を起動してからもう一度試してください。
```

アクション: `もう一度試す`

**使わないコピー:** 「申し訳ありません」「エラーが発生しました」「予期しないエラー」

---

#### セッション中にOllamaが切断

```
接続が切れました
```

補足テキスト:
```
Ollama との接続が途切れました。
対話内容はまだ残っています。接続を確認してください。
```

アクション: `もう一度試す`

セッション画面では、エラー文の下に retry ボタン1つを置いた静かなカードとして表示する。
モーダルにはしない。対話履歴とユーザー入力は保持されたまま。

設定変更が必要な場合はセッションを終えてから設定画面へ移る前提とし、
カードからは「設定を開く」を出さない（途中セッションを失わせないため）。

---

#### Markdown生成失敗（要約生成失敗）

ユーザーへの通知は出さない——対話ログだけで保存し、要約部分は空で保存する。
ログが残ることの方が要約より重要。

---

#### 掘り跡の読み込み失敗

```
この掘り跡を開けませんでした
```

補足テキスト:
```
ファイルが移動または削除されている可能性があります。
```

## CLIコピー（ターミナル向け）

CLIはGUIより余白が少ない。コピーは短く。色は最小限（richを使う場合）。

| 状態 | 出力テキスト |
|------|-------------|
| 起動時 | `Diguest` （プロダクト名のみ） |
| Ollama接続確認中 | `connecting...` |
| 接続成功 | `ready.` |
| テーマ入力促し | `今日、何を掘りますか？ ` |
| Ollama未起動 | `Ollama が起動していません。` |
| 補足 | `  $ ollama serve` |
| 保存完了 | `→ saved: 20251201_103045_最近の違和感.md` |
| 終了 | （何も出さない、またはファイルパスのみ） |

**CLIで使わないもの:**
- ASCII アート・ロゴ
- 起動メッセージ（「セッションを始めます！」など）
- 完了メッセージに過剰な装飾（✓✓✓ など）

## Markdown内のコピー（掘り跡ファイル）

生成されるMarkdownファイル内のコピー。AIが生成するセクションではなく、テンプレート的な固定テキスト。

| 要素 | コピー |
|------|--------|
| フッター | `_Generated by Diguest_` |
| 対話ログのユーザー発言ラベル | `**You:**` |
| 対話ログのAI発言ラベル | `**Diguest:**` |

セクション見出し（`## 対話の要約` など）はAIが生成するわけではなく、テンプレートとして固定。
AIはその下のコンテンツを生成する。
