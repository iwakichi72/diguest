# Diguest — UI Brief

## 設計思想

### UIが表現すること

Diguestのインターフェースは「道具」ではなく「場所」でなければならない。

ユーザーがDiguestを開くのは、答えを求めるときではない。まだ言葉になっていないものを掘り起こしたいとき、座って自分と向き合いたいとき、そのための静かな場所として機能すること。

ChatGPTのUIは「質問する→答えが返ってくる」という構造を視覚的に体現している。Diguestはその逆——「自分が語る→問いが返ってくる」という構造を体現しなければならない。これはレイアウト・タイポグラフィ・コピーのすべてに影響する。

### 3つの禁止

**ダッシュボード化しない**  
メトリクス・グラフ・ストリーク・達成バッジは置かない。数値はセッション内の発言数のみ、それも主張しない場所に置く。

**チャットUI化しない**  
吹き出し・アバター・「送信」ボタン・既読マークは置かない。対話画面はチャットではなく、往復書簡のような縦の流れとする。

**アシスタントUIにしない**  
「お手伝いします」「何でも聞いてください」のような構造を持たせない。AIが先に語りかける画面はない。ユーザーが先に口を開く。

## ビジュアル言語

### メタファー：地下を掘る

Diguestの語源は "Dig" + "Digest"。思考の地層を掘り下げるイメージ。

- 色は地の色（深い炭・温かみのある黒）
- タイポグラフィは紙に書かれた文字のような密度
- アニメーションは遅く静か（フェードが基本、スライドは使わない）
- UI要素は少なく、必要なときだけ現れる

### 空間の使い方

コンテンツの最大幅は **680px**（ワンカラム）。余白は惜しまない。スクロールを恐れない。詰め込まない。

ナビゲーションは画面の主役ではない。常にペリフェラルな位置に置く。

### ライト/ダークモード

プライマリはダークモード（夜の日記、内省的な時間帯を想定）。ライトモードは紙の質感。どちらも色数は変わらない——差し色は1色のみ。

## 画面定義

### 1. ホーム画面

**目的**: 新しいセッションを始めること、または過去のノートを見ること。ただそれだけ。

**レイアウト:**
```
──────────────────────────────────
  
  Diguest                    [設定]
  
  ──────────────
  
  今日、何を掘りますか？
  
  [新しいセッションを始める]
  
  ──────────────
  
  過去のノート
  
  2025-12-01  最近もやもやしていること
  2025-11-28  なぜ小説が書けなくなったか
  2025-11-22  仕事への違和感の正体
  
──────────────────────────────────
```

**設計原則:**
- 「新しいセッションを始める」ボタンは1つだけ。CTA競合なし
- ノート一覧は日付＋テーマのみ。文字数・発言数・タグは表示しない
- 検索バーはない（MVP）
- ヘッダーにプロフィール・通知・バッジの類は置かない
- ノートが0件のとき：「まだノートはありません」ではなく「最初の問いを立ててみよう」

---

### 2. 新規セッション画面

**目的**: 今日掘りたいテーマを一言で表す。それだけの画面。

**レイアウト:**
```
──────────────────────────────────
  
  [← 戻る]
  
  
  
  今日、何を掘りますか？
  
  ┌──────────────────────────┐
  │                          │
  │  （テーマを入力）         │
  │                          │
  └──────────────────────────┘
  
  テーマは短く、一言で。
  答えではなく、問いでも構いません。
  
  [掘り始める   →]
  
  
  
──────────────────────────────────
```

**設計原則:**
- 入力フィールドは1つだけ。マルチフォームにしない
- プレースホルダーは「例：最近の違和感」ではなく、もっと余白のある表現
- Enterキーで送信可能（ボタンは補助）
- テーマ未入力では「掘り始める」を押せない（しかしエラーメッセージは出さない——ボタンが押せないだけ）

---

### 3. 対話画面

**目的**: ユーザーが語り、Diguestが問いを返す。思考の往復。

**レイアウト:**
```
──────────────────────────────────
  なぜ小説が書けなくなったか      [終わる]
  ─────────────────────────────
  
  
  
  書けなくなったのは、去年の秋ごろから
  だと思います。
  
  
  ╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌
  
  「書けない」というとき、どんな状態に
  なっていますか？ 書こうとして止まる
  のか、書く気自体が起きないのか。
  
  ╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌
  
  
  
  ──────────────────────────────
  ┌──────────────────────────┐
  │                          │
  │                          │
  └──────────────────────────┘
  Shift+Enter で改行  ·  Enter で送信   5回
──────────────────────────────────
```

**視覚的区別:**
- **ユーザーの発言**: 通常テキスト、左揃え
- **Diguestの問い**: 破線ルール（╌╌╌）で上下を囲む。斜体。わずかに色が異なる
- アバター・アイコン・ラベル（「You:」「AI:」）は置かない
- 吹き出しは使わない

**インタラクション:**
- 入力エリアは自動リサイズ（最小2行、最大6行）
- AIの応答はストリーミング表示（文字が流れる）
- ストリーミング中は入力エリアを無効化（送信ボタンなし、Enterも無効）
- 「終わる」は右上に、しかし目立たせすぎない（誤タップ防止のため確認なし——CLIの `exit` に近い感覚）
- 発言回数は右下に `5回` のような形でうっすら表示

**Diguestが考えている間（ストリーミング前）:**
- テキストカーソルが点滅するだけ。スピナーなし、「考え中...」テキストなし
- 沈黙を演出する

**空スクロール領域（最初）:**
- 入力フィールドより上は広い余白
- 「準備はできています。」のような文言なし——ただ白紙

### 4. Markdownプレビュー画面

**目的**: セッション終了後に生成されたノートを確認する。

**レイアウト:**
```
──────────────────────────────────
  [← ノート一覧]
  
  2025-12-01 · llama3 · 8ターン
  
  # なぜ小説が書けなくなったか
  
  ## 対話の要約
  
  （要約テキスト）
  
  ## 掘り出されたもの
  
  - （発見1）
  - （発見2）
  
  ## 対話ログ
  
  （ログ全文）
  
  ─────────────────────
  [Markdownをコピー]   [エディタで開く]
  
──────────────────────────────────
```

**設計原則:**
- プレビューはMarkdownのレンダリング表示（生テキストではない）
- フォントは本文用セリフ体（読むモードを強調）
- 編集機能はない——このツールでは読むだけ
- 「共有」ボタンは置かない（ローカルツールの哲学）
- 「エディタで開く」はOSのデフォルトアプリで開く（ローカルファイル）

---

### 5. 保存済みノート一覧

**目的**: 過去のセッションを日付順に眺める。

**レイアウト:**
```
──────────────────────────────────
  Diguest                    [設定]
  
  ──────────────
  
  [+ 新しいセッション]
  
  ──────────────
  
  12月
  
  01  なぜ小説が書けなくなったか
  
  11月
  
  28  最近もやもやしていること
  22  仕事への違和感の正体
  18  創作と生存の関係
  
──────────────────────────────────
```

**設計原則:**
- 月ごとのグルーピング（見出し）
- 各エントリは日付＋テーマのみ
- タグ・ラベル・ターン数・文字数は表示しない
- ホバー時に行がうっすらハイライトされるだけ
- ソート変更・フィルタリング・検索は置かない（MVP）

---

## アニメーション原則

| 動作 | 種類 | 時間 |
|------|------|------|
| 画面遷移 | フェードイン | 200ms |
| Diguestの応答出現 | 文字ストリーミング | リアルタイム |
| ページ内スクロール（新発言） | スムーズスクロール | 300ms |
| ボタンホバー | opacity変化のみ | 150ms |
| ノート一覧の行ハイライト | background-color | 100ms |

**使わないもの:** スライド・バウンス・スケール・回転・シェイク

---

## ナビゲーション構造

```
ホーム
  └── 新規セッション → 対話画面 → Markdownプレビュー
  └── ノート一覧 → Markdownプレビュー
```

戻るボタンは常に左上。グローバルナビゲーションバーは持たない。
