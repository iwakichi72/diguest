# Diguest — 実装タスクリスト

このリストはSwiftUI Macアプリ版を基準にする。

## P0: MVP補強

- [x] **P0-1** SwiftUIネイティブアプリの骨格を作る
  - ホーム、テーマ入力、セッション、保存前プレビュー、ノート表示、設定画面

- [x] **P0-2** Ollamaへ直接接続する
  - `/api/tags` で接続確認
  - `/api/chat` でストリーミング対話
  - 要約生成は非ストリーミング

- [x] **P0-3** Markdown保存を実装する
  - `~/diguest/` へ保存
  - 同名ファイルは連番
  - 要約生成失敗時もログを残す

- [x] **P0-4** Apple Speech on-device音声入力を実装する
  - `supportsOnDeviceRecognition` を確認
  - `requiresOnDeviceRecognition = true`
  - ネットワーク認識へフォールバックしない

- [ ] **P0-5** GUI実機確認
  - 初回権限プロンプト
  - 音声入力の開始/停止
  - Ollama未起動時の表示
  - 保存後のノート表示

## P1: 信頼性

- [ ] **P1-2** frontmatterの安全性を上げる

- [ ] **P1-3** 設定保存の検証を追加する

- [ ] **P1-4** アプリバンドルの配布形態を整理する

  - notarizationの要否
  - アイコン
