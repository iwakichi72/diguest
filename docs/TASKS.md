# Diguest — 実装タスクリスト

このリストは現在のNext.js WebUI版を基準にする。初期セットアップやコア対話フローは既に実装済みのため、ここでは「MVP補強」と「次フェーズ」に必要な作業だけを管理する。

## P0: MVP補強

- [ ] **P0-1** AI応答の禁止表現テストを追加する
  - 対象: `lib/prompts.ts`, APIレスポンス検査またはテスト
  - 見る表現: `しましょう`, `すべき`, `おすすめ`, `してみてください`, `効果的です`

- [ ] **P0-2** `/notes` の月別ノート一覧を追加する
  - Server Componentで `listNotes()` を呼ぶ
  - 月見出し + 日付 + テーマのみ表示する
  - 検索、タグ、ターン数、文字数は出さない

- [ ] **P0-3** Ollama接続エラーの導線を整える
  - `/api/health` の結果をUIに反映する
  - 未起動時はCOPY_GUIDEの文言を使う
  - `もう一度試す` を追加する

- [ ] **P0-4** セッション中の下書き保護を追加する
  - テーマ、開始時刻、messagesを一時保存する
  - まずは `localStorage` を候補にする
  - 保存完了後に下書きを削除する

- [ ] **P0-5** 設定確認・編集画面を追加する
  - `/settings`
  - Ollama URL、モデル、ノート保存先を表示・保存する
  - `~/diguest/config.json` と同じスキーマを使う

## P1: 信頼性

- [ ] **P1-1** Markdown保存のE2E確認を追加する
  - 要約生成失敗時もログだけ保存されること
  - 同名ファイルが連番保存されること
  - 日本語ファイル名がURLから開けること

- [ ] **P1-2** frontmatterの安全性を上げる
  - `theme` に `:` や改行が入ってもMarkdown/YAMLが壊れないようにする
  - 必要ならYAML文字列としてクォートする

- [ ] **P1-3** 保存前プレビューから戻った後も対話内容が残ることを確認する

## P2: 次フェーズ

- [ ] **P2-1** 問いのモードを設計する
  - 静かに整理
  - 違和感を掘る
  - 創作テーマを掘る
  - 価値観を掘る

- [ ] **P2-2** Markdownテンプレートの最小カスタマイズを設計する
  - セクション名の変更程度に留める
  - 複雑なテンプレートエンジンにはしない

- [ ] **P2-3** モデルプリセットを設計する
  - 速い
  - 深い
  - 日本語安定

## P3: 採用しない・後回し

- [ ] タグ・カテゴリ管理
- [ ] 統計・ストリーク
- [ ] ダッシュボード
- [ ] PDFエクスポート
- [ ] 共有機能
- [ ] クラウド同期
- [ ] AIによる過去ノート自動参照
- [ ] 吹き出し、アバター、提案チップなどのチャットUI

## 実装順序

1. P0-1でDiguestの哲学を守る
2. P0-2で保存したノートを再訪できるようにする
3. P0-3でローカルOllamaの摩擦を下げる
4. P0-4で対話内容の喪失を防ぐ
5. P0-5で設定をUIから確認できるようにする

この順序なら、便利機能より先に「問い手としての一貫性」と「ノートが残る安心」を固められる。
